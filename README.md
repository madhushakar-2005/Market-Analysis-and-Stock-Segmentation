# Market-Analysis-and-Stock-Segmentation
 S&amp;P 500 Stock Segmentation Using Adapted RFM  Clusters 491 S&amp;P 500 shares (2021–2024) on risk/return (weekly return, beta) and adapted RFM (Recency, Frequency, Monetary from unusual-volume days), using Ward and K-means, plus an RFM sensitivity test and a star-schema data mart.
